Areal Survei

Processing aerial photo tiles of the UGM vocational school area using ground control points obtained from GNSS-Geodetic measurements. Using Agysoft Metashape Professional, the processing produced better aerial photos that corresponded to the original coordinates on the ground.
Processing aerial photo data using Agysoft Metashape Professional into DEM (Digital Elevation Model) data. DEM data will represent the elevation of an area in meters or feet. This data shows the elevation of the area around the UGM vocational school campus.
Processing LiDAR (Light Detection and Ranging) data to generate DSM (Digital Surface Model) data for part of the Special Region of Yogyakarta Province. Processing LiDAR (Light Detection and Ranging) data to generate DTM (Digital Terrain Model) data for part of the Special Region of Yogyakarta Province. DTM (Digital Terrain Model) is elevation data that is not affected by the elevation of land cover above it, such as vegetation and other elements.

GNSS

Measurements are taken using GNSS Geodetic with the RTK CORS method. This method involves two things, namely a reference station or CORS and an RTK receiver used in the field. The RTK CORS method has a system that utilizes two stations, namely a reference station (CORS) and an RTK receiver station.
Performing measurements using Geodetic GNSS with the RTK RADIO method. RTK RADIO works by connecting the reference station with the rover. The connection between the reference station or base and the rover is used to correct the data obtained from the rover. The measurement method using RTK RADIO is carried out by setting up the GNSS equipment on the JKGN (National Gravity Control Network).
Performing measurements using Geodetic GNSS with the STATIC method. The static method works by utilizing signals from existing satellites; the more satellite signals connected, the better the data obtained. The static method produces better data compared to other methods, as it requires a considerable amount of time to collect data at a single location.

Land Measurement

Perform detailed measurements of the situation using a total station. A total station works by reflecting infrared light from the device toward a prism as a target. The prism then reflects the light back toward the device. The reflected light is then used to calculate distance and other measurements.
Processing detailed measurement data using a total station to create a contour map of part of the river in the Wisdom Park UGM area. Processing is carried out using ArcGIS, or more specifically ArcMap.
Processing detailed measurement data using a total station to create DEM data for part of the river area in the Wisdom Park UGM area. Processing is carried out using ArcGIS, or more specifically ArcMap.
